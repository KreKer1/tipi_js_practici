## Запуск ПР4–ПР6

Из папки нужной практики выполните `npm start`. В Windows PowerShell можно использовать `npm.cmd start`.

- **ПР4** — приложение на `http://127.0.0.1:5504/`.
- **ПР5** — API на `http://127.0.0.1:5505/api`. Для запуска клиента выполните `npm run client` во втором терминале из той же папки.
- **ПР6** — приложение на `http://127.0.0.1:5506/`, API на `http://127.0.0.1:5505/api`.

ПР5 и ПР6 запускайте по очереди, поскольку их API используют один порт. Команды проверок и подробности запуска указаны в README каждой практики.
